# ADR-0003: Dual-Threshold Traffic Light Scoring Model

## Status: Accepted

## Context

20 个财务指标需要聚合成用户可理解的评分。可选方案：

- A）简单加权评分：每个指标按阈值打分加总
- B）红黄绿灯：每个指标标色，不做总分
- C）先 B 再 A：红黄绿灯矩阵 + 加权总分

## Decision

采用方案 C：双重阈值评判 + 红黄绿灯矩阵 + 加权总分。

**双重阈值**：每个指标同时评判两个维度

- 绝对值水平：当前值是否健康（优良🟢/关注🟡/警告🔴）
- 同比变化率：趋势是否稳定（<20%🟢/20-50%🟡/>50%🔴）
- 最终灯色 = max(绝对值灯, 变化率灯)

**加权总分**：四维度各 25 分 = 100 分

- 🟢 = 该维度满分 / 指标数
- 🟡 = 半分
- 🔴 = 零分
- 85-100 = 🟢健康 | 60-84 = 🟡关注 | <60 = 🔴警告

20 个指标及其阈值硬编码在 metrics/traffic_light.py 中，不依赖 LLM 判断。

运营效率维度使用固定绝对值阈值（与其他维度一致），特定行业（如白酒/酿酒）通过 `INDUSTRY_OVERRIDES` 字典覆盖存货周转率等指标阈值。

## Consequences

- 输出像专业分析师的报告，而非 AI 猜测
- 红黄绿灯矩阵直观，总分简洁，两种受众都满足
- 阈值硬编码确保结果确定性和可重复性
- 行业覆盖（如白酒）通过 `INDUSTRY_OVERRIDES` 实现，无需拉取行业均值
