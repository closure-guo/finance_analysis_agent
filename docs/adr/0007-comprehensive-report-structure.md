# Comprehensive 报告分层结构

Comprehensive 分析需要把 FA（向后看，财务健康诊断）和 IA（向前看，投资价值判断）合并成一份综合报告。初始实现是简单拼接两份完整报告，但存在两个问题：

1. 报告冗长（FA 约 5000 字 + IA 约 4000 字），用户难以快速获取核心结论
2. 双方观点可能分歧（如 FA 认为偿债极优，IA 认为估值过高），需要显性展示

## 决策

采用三层结构：

1. **综合结论**（300-500 字）— LLM 基于双方分析生成，给出统一的投资建议
2. **核心观点对比表格** — 代码硬拼，从 `traffic_lights` / `metrics` 提取双方共同关注的指标，标出分歧点
3. **完整报告附录** — 原始 FA 报告（8 章）和 IA 报告（7 章）完整保留

## 为什么不是融合模式

融合模式（让 LLM 基于双方数据重写一份精简报告）需要第三次 LLM 调用，成本更高且可能丢失细节。分层模式兼顾"快速决策"（读前两层）和"深入研究"（读附录）两种使用场景。

## 免责声明位置

综合报告正文和文件导出都要附加免责声明。仅放在文件末尾会导致 Gradio Markdown 渲染时看不到。
