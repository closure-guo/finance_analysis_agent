## 2. 门禁与纪律合规

- **干净窗口**：三个决策日距跑批日（2026-09-26±）均 ≥20 交易日（最晚决策日 2025-04-07，余量 ~110 个交易日）；assert_clean_window 以 000300 交易日历判定。
- **深历史执法**：切点「2025 年前样本永久通路验证」在回测代码中**无执法点**（缺口登记 issue #172）——本批由驱动脚本 `tests/scripts/formal_backtest_driver.py` 以日期裁剪执法：决策日强制 ∈ [2025-01-01, 2026-08-26]，本批三日全部非深历史。
- **泄漏探针**：formal 强制；对 3 个 distinct 决策日各探一次、最差态汇总；命中率 >0.60 → 整批降级「泄漏污染下的上界证据（真实 skill ≤ 读数）」。
- **regime 覆盖**：三 regime 全覆盖（含唯一 bear 窗口），不触发 spec「干净窗口优先、结论限定已覆盖 regime」的降级条款；结论限定词仍按报告披露。
- **结论句形态**：runner 合同为超额 Sharpe vs 基线（buy_hold/macd/kdj/rsi）的 block bootstrap CI（含 0 → 无显著差异）；与预登记 §0「均值超额 CI」的对应关系随报告披露——两口径读数并列，互不替代。

## 6. 执行结果与判读（2026-09-25 深夜，batch 完成）

**执行**：全量 30 样本 × 3 重复 = 90 回放，当晚完成（GLM-5.3 实测远快于 P1 的 9 分钟/回放估计）；formal 门禁三关全过（预登记绑定 valid / 干净窗口通过·最少余量 360 交易日 / 探针可测），positioning=skill；报告 `evals/backtest/results/formal-2026q3.md`（status: active）。

**判读（按预登记红线，优先级高于 runner 机械结论）**：

1. **本批对「赚不赚钱」无判定力**——可执行决策仅 ~4/30（600515 bear sell、601058 bull buy×3 一致、600515 sideways sell、601058 bear buy 仅 1/3），绩效表（system Sharpe -1.51 vs 基线）建立在个位数样本上；runner 机械输出「无显著差异」按 §1 红线（可执行 <10 不作能力表述）**不构成能力判断**，正确判读是「分辨率远不足以判定」。
2. **有效读数三条**：① 决策复现性 mean agreement 0.9222（90 回放，excluded_low_consistency 为空）——管线输出稳定性好，是方法学资产；② 泄漏探针最差窗口方向命中率 **60% 恰在阈值上**（未触发降级，边界踩线如实披露——模型对 2025 年初行情方向存在不可忽略的「记忆」，后续批次的探针判读应从严）；③ 可执行率 ~13%（4/30），与生产取证 11% 同族——b 方案结构化申报下的审慎姿态跨市况稳定。
3. **结构洞察（本批 15M tokens 的净产出）**：回测腿被可执行率钳制——扩样无解（n=100 → 可执行 ~7-13 条仍 <10 红线；n=150+ 需 ~75M tokens 不成比例）。「赚不赚钱」的判定**只能由 forward 腿日历积累产出**（每日 10 决策持续攒可执行样本，~11 月底-12 月初可达 n≥30 结算）。回测腿的定位回到它该在的地方：管线稳定性/一致性/探针的年度体检，而非能力判定。
4. 后续：探针踩线的边界语义（60%=阈值，>60% 才降级）建议在下一版预登记修订时收紧为 ≥60% 或加披露档；#172 深历史执法、一致率剔除通道的失败样本标注（_failed → agreement=0）随驱动沉淀，库层收口挂 #172。
