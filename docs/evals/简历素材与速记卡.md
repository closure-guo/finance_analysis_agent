## 素材 1：校验器从"契约病误诊 75%"到"准度门禁"（核心叙事）

> 为金融多 Agent 系统的引用校验器建立准度闭环：**逐条分桶归因**发现 75% 的
> FAIL 不是 LLM 幻觉而是四类契约病（负索引/词表未统一/相对容差/期次语义），
> 修复后三标的 FAIL 率降至 **3.5%/0%/0%**；随后构建**对抗基准集 v1.1**（70 条：
> 容差边界 ±{0.3,0.5,0.7,1}% 四档近失配 + 语义错位对抗子集，构造即标签免 LLM），
> 冻结 F1=**1.0**、semantic 检出率 **1.0**；并用 **注入式故障演练**（容差 0.5%→5%）
> 实证 CI 门禁有效（F1 1.0→0.5833、exit 1，还原全绿）。

**面试可讲**：75% 误诊的归因方法（分桶 → 定位契约而非模型）；"构造即标签"的
免 LLM 基准设计（为什么 v1.1 不需要 κ）；门禁的防回归价值（baseline-v2 r3 事故教训）。

## 素材 2：评估体系四层（方法论文档化）

为金融多 Agent 系统设计并实现**四层评估体系**：
1. **校验器自评估层**：对抗基准集 + F1 准度门禁（CI 内嵌，退步 >0.02 阻断合并）；
2. **产出质量层**：Langfuse 实验回归 + 配对 bootstrap（B=10,000）显著性门禁；
3. **决策回测层**：分层市场状态回放（防前视偏差的数据时点截断）+ block bootstrap
   置信区间 + 规则基线对比（Buy-and-Hold/MACD/KDJ/RSI）；
4. **架构归因层**：数据对齐消融（三变体 × 同 state 快照）。

## 素材 3：消融——辩论层增量（最有含金量，含诚实边界）

> 通过数据对齐消融实验（三变体 × 同 state 快照 × 3 标的 × 3 次重复，配对
> bootstrap B=10,000）量化多智能体辩论层的增量价值：**Bull/Bear 辩论层增量
> 未获统计支持**（95% CI 含 0）；**风险辩论+基金经理层使 decision_grounding
> 显著退步**（95% CI [-1,-1]）；据此裁剪管线可节省约 **41% token**
> （full 1,076,984 vs analysts 632,293）。

**诚实边界（防被挑战）**：①当前 n=3 标的 × 3 重复，CI 较宽；②judge 跨模型校准
（±1 一致率 84%）显示 judge 分数带 ±1 噪声——"full 层 decision_grounding Δ-1 显著
退步"的 -1 在噪声带内，该子结论需重校准后重验（辩论层"未获统计支持"不受影响）；
③扩样预算见速记卡。这是**通路验证**级别的初步证据，不是最终统计结论。

## 素材 4：回测器（防前视偏差的决策回测）

> 实现 A 股决策回测器：**防前视偏差的数据时点截断**（财报按披露截止日而非
> 报告期）、分层市场状态抽样、与规则基线（Buy-and-Hold/MACD/KDJ/RSI）对比、
> **block bootstrap 显著性检验**（规避 TradingAgents 小样本高夏普陷阱）。
> 成本实测：单次五层回放 ≈27 次调用 / 16.6 万 token，可精确外推全量预算。

## 素材 5：完整叙事线（串起所有素材）

1. 发现 **75% 引用校验失败率** → 2. 逐条分桶归因发现全是**契约病而非幻觉**
   → 3. 修复四类契约 → 4. 建**对抗基准集量化验收**（FAIL 75% → 3.5%/0%/0%）
   → 5. 用**消融实验**证明架构价值并裁剪成本（41% token）→ 6. **CI 门禁**防止复发。
