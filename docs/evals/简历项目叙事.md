## 一句话定位

一个**多 Agent 辩论式 A 股分析系统**（LangGraph 五层：4 分析师 → Bull/Bear 辩论 → Trader → 风控辩论 → 基金经理审批），以及围绕它建成的**四层评估体系**——把「LLM 输出是否可信」从感觉变成可度量、可回归、可归因的工程问题。

## 完整叙事线（30 秒版）

1. 发现**75% 引用校验失败率** → 2. 逐条分桶归因发现**全是契约病而非幻觉**（负索引/词表分裂/相对容差/期次语义四类）→ 3. 修复四类契约 → 4. 建**对抗基准集量化验收**（FAIL 75% → 三标的 3.5%/0%/0%）→ 5. 用**数据对齐消融**证明架构价值并裁剪成本（41% token）→ 6. **CI 门禁**防止复发 → 7. 二次校准又挖出三层工程缺陷（judge 漂移/#111/#112），把「人工校准」变成「确定性指标 + 工程缺陷排查」。

每一步都有 artifact：incident 022 / v1.2.md / pilot.md / ci-gate-verify.md / 记录文档 §一~§十。

## 项目背景（情境）

- 系统：A 股多 Agent 辩论式报告，五层流水线，SSE 流式，Langfuse 全链路追踪
- 核心痛点：**LLM 输出可信度不可度量**——校验器误报率高达 75%，消融/回测结论全建立在不靠谱的指标上
- 我的角色：评估体系设计 + 校验器准度闭环 + 回测/消融设施 + 数据驱动的管线诊断

## 主要工作（任务 + 行动）

### A. 校验器准度闭环（75% → 3.5%/0%/0%）

**任务**：引用校验器大面积 FAIL，不知道是模型幻觉还是校验器自身病。

**行动**：
- 逐条**分桶归因**（value_mismatch / path_unresolvable / semantic_term/period / internal_inconsistency），定位 75% FAIL 是四类**契约病**而非幻觉：负索引解析、指标词表分裂、相对容差失真、期次语义错位；
- 修复契约 + prompt 声明纪律（metric_name/period 申报）；
- 建**对抗基准集 v1.2**（81 条，构造即标签、免 LLM 标注）：容差边界 ±{0.3,0.5,0.7,1}% 四档近失配、语义错位对抗子集、v3 新路径样本；
- 接 **CI 回归门禁**：F1 ≥ 0.90 且相对冻结基线退步 > 0.02 即阻断；注入式故障演练验证门禁有效（F1 1.0→0.58、还原全绿）。

**结果**：FAIL 75% → 三标的 3.5%/0%/0%；门禁从「测试全绿但校验器悄悄退化」中把回归兜住。
**面试可讲**：契约病 vs 幻觉的判定方法论；「构造即标签」的免 LLM 基准设计；故障注入验证门禁。

### B. 决策回测器（防前视偏差的历史回放）

**任务**：回测设施从未真跑（首跑即崩），且要防前视偏差 + 小样本高夏普陷阱。

**行动**：
- 数据时点截断（财报按**披露截止日**而非报告期）、分层市场状态抽样、规则基线（B-H/MACD/KDJ/RSI）对比、**block bootstrap** 置信区间；
- 修首跑暴露的设施缺陷（TradeDecision 类型、250 日 K 线深度、空 K 线静默降级）；
- **基线 horizon 对齐**：基线只在系统持有窗口切片重算，消除 1500 日 vs 单笔不可比；
- 成本实测：单次五层回放 ≈27 次调用 / 16.6 万 token，精确外推全量预算。

**结果**：全链路跑通 + 三核查（截断/结算/成本）实证；绩效表（通路验证级，无统计意义）。
**面试可讲**：披露截止日截断怎么防前视；block bootstrap 怎么规避 TradingAgents 式高夏普陷阱；**实测 token 成本做样本量-预算表**。

### C. 数据对齐消融（辩论层的增量价值）

**任务**：多 Agent 辩论架构到底值不值——用数据说话，不是讲故事。

**行动**：
- 三变体（单分析师直出 / +Bull/Bear 辩论 / 完整五层）× **同 state 快照** × 配对 bootstrap（B=10,000）；
- 一次跑出真数据：辩论层增量**未获统计支持**（CI 含 0）、完整层 decision_grounding **Δ-1（CI[-1,-1]）**、据此裁剪管线省 **41% token**；
- **诚实边界**：n=3 通路验证；judge 维度结论因后续发现的三层工程缺陷（评分者漂移 / #111 FM 理由丢失 / #112 维度适用性）暂不作定论——**这种「自己推翻自己」的过程本身就是方法论加分项**。

**结果**：第一份消融真数据 + 完整的方法论反思链（三层问题逐层挖出并修复）。
**面试可讲**：「同快照对齐消融」怎么把架构差异从模型噪声里隔离出来；CI 含 0 的措辞纪律；发现校准伪影的完整排查链。

### D. 评估体系四层（方法论文档化）

**行动**：把上述工作统一为四层：校验器自评估层（基准+门禁）/ 产出质量层（Langfuse 回归+配对 bootstrap 门禁）/ 决策回测层（防前视回放+block bootstrap）/ 架构归因层（对齐消融）。

**结果**：README「评估体系」小节 + `docs/evals/` 全套档案。
**面试可讲**：为什么这四层恰好覆盖「校验器可信 → 产出质量 → 决策可信 → 架构价值」——每一层都有独立的数据证据链。

## 诚实边界（被挑战怎么答）

- **「n=3 是不是太小」**：是。通路验证级，扩样预算表已备（90 run 数字 + CI 收窄预估），正式结论需扩样——但**方法论本身（对齐消融 + 配对 bootstrap + 措辞纪律）不依赖样本量**。
- **「judge 维度结论打问号」**：正确。且我能说出三层原因（双评分者漂移 / #111 / #112）和每一层的修复——这比一个「看起来完美」的数字更可信。
- **「F1=1.0 是不是虚高」**：是。v1.1/v1.2 标签构造性一致，测量含构造成分；价值在**防回归**而非准度定论——门禁真正的意义是「改了契约门禁必响」（故障注入已证）。
