# 002: 报告准确性复盘 — 茅台 FA 分析偏差

**日期**: 2026-05-26
**状态**: 部分修复
**关联 Issue**: #5 (Bug: 指标计算与评分模型准确性)

---

## 背景

Phase 3 端到端测试（600519 贵州茅台）生成的 FA 报告，数据基本准确但定性判断严重偏差。

---

## 根因分析（三层）

### 第一层：指标体系不适合行业

- 通用 20 指标无法适配所有行业（白酒存货是增值资产、银行杠杆天然高）
- 缺少关键前瞻指标：合同负债（经销商打款意愿）、行业周期位置
- **修复方向**：指标选择需要行业感知，不同行业用不同指标集

### 第二层：归因逻辑错误

- 经营现金流下降 33% → 系统归因为"利润含金量低"，实际原因是财务公司存款变动（非核心业务）
- ROE 下降 → 系统归因为净利率拖累，实际是营收首次下滑导致的规模问题
- **修复方向**：归因需要结合行业背景和具体变动原因，不能纯看数字变化

### 第三层：缺行业上下文

- 无同业对比 = 无参照系，孤立数字没有意义
- 2025 白酒行业整体下行 800 亿营收，茅台温和回调实属优秀
- **修复方向**：分析必须嵌入行业周期和竞争格局

## 对茅台报告的具体修正

| 报告结论                      | 实际情况                                 | 错误类型            |
| ----------------------------- | ---------------------------------------- | ------------------- |
| 存货周转率 0.08 次 = 库存积压 | 实际约 0.26 次，且基酒储存是商业模式核心 | 计算错误 + 行业误判 |
| 利息覆盖 3994x = 红灯         | 绝对值极安全，不应因同比下降标红         | 评分模型缺陷        |
| "高盈利、弱现金、低效率"      | 2000 亿现金、91% 毛利率，最健康公司之一  | 归因逻辑反了        |
| 60.8 分"关注"评级             | 各维度极优，应为"健康"                   | 评分模型缺陷        |
| 净利率下降拖累 ROE            | 营收首次下滑是因，净利率变化是果         | 因果倒置            |
| 未提及合同负债                | 合同负债降 16.5% 是核心前瞻信号          | 指标缺失            |
| 未提及行业周期                | 白酒行业 2025 年整体下行                 | 上下文缺失          |

## 设计原则（后续重构依据）

1. **指标行业适配**：不同行业用不同指标集和阈值
2. **归因需要上下文**：数字变动必须有原因分析，不能纯机械判断
3. **前瞻指标**：合同负债、行业周期等先行指标比滞后指标更有价值
4. **自校验**：自算值与 AKShare 预计算值交叉验证
5. **有参照系才有意义**：同业对比是分析的地基，不是可选章节
