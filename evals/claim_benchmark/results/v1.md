## 测量口径（判读前必读）

- **校验器裁决 = 离线复判**（`rejudge.rejudge_claim`）：管线 state 不落库，无法重跑 field_ref 解析层；按当前契约从容割到的 `(ground_truth, delta)` 重建裁决层判定。复判公式与 `citation.py` 由钉死测试锁定（`tests/evals/claim_benchmark/test_rejudge.py`）。
- **F1 核心排除项**（共 120/210，单独披露）：
  - 复判不可得 92 条：llm_inference 契约跳过 / entity 等类型 / gt 缺失（词表疾病样本）/ 比较型 greater-less（delta 无符号）；
  - regression 87 条：修复前 trace 的索引/词表契约疾病样本（与上一项有重叠），人工标签分布 FAIL 6 / UNVERIFIABLE 59 / PASS 22——回归考题按口径②③标注，解析层无法离线重建，不入 F1。
- **标签来源声明**：本次 LLM 初标与离线复判共享同一容差规则文本（绝对 0.01 / 相对 0.5%），F1=1.0 含构造性一致成分，**不构成独立金标准**——这正是人工抽检 κ 环节存在的理由。

## 考卷构成与数据形态披露

- 来源：`claims_raw.jsonl` 619 条 claims（**带病 487 + post-fix 132**，修复合入分界 2026-08-29T04:05Z）；带 claim 的历史 session 仅 **19 个**（104 条 trace 中 85 条 citation_report 为空 results）。
- 考卷 210 行（clean 150 / near-miss 40 / hedged 20）。
- 类型分布实测：numerical 73.8% / computational 15.7% / entity 10.5% / **comparative 0%**——历史报告从未产出 comparative 类型 claim（目标 ~15% 不可满足，事实披露，非抽样缺陷）。
- 单一 session 上限：目标 8 条，但 19 sessions × 8 = 152 < 210 行 → **自动放宽至 16/trace（最小可行）**，防一家独大意图仍保留（最大 session 86 条 claim 中最多取 16）。
- regression 回归考题 87 条入卷（修复前疾病样本），测量时单独披露不入 F1 核心。

## 复现命令（κ 定稿后刷新基线）

    --input evals/claim_benchmark/data/benchmark_v1_llm_labeled.jsonl \
    --human evals/claim_benchmark/data/human_spotcheck.csv \
    --out evals/claim_benchmark/data/benchmark_v1_labeled.jsonl

    --labeled evals/claim_benchmark/data/benchmark_v1_labeled.jsonl
