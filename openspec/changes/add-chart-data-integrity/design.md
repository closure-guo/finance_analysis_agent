# Design: add-chart-data-integrity

## Approach

三层修复，每层职责单一：

1. **数据层（akshare_client._rename_parent_cols）**：列名候选归一化匹配优先。归一化 = 去除全部空白变体（`\u3000`/`\xa0`/空格/制表符）。候选集覆盖新浪两代模板与东财措辞：归母净利润 = {归属于母公司所有者的净利润, 归属于母公司的净利润, 归属于母公司股东的净利润}；归母权益 = {归属于母公司股东权益合计, 归属于母公司股东的权益, 归属于母公司股东权益, 归属于母公司所有者权益合计, 归属于母公司所有者的权益, 归属于母公司股东的所有者权益}。目标列已存在时跳过（幂等）。全部候选未命中 → 既有列位 50/137 回退（保住原「编码损坏」修复场景）。真实银行/制造业报表固化为 tests/fixtures CSV，测试直接读 fixture 断言解析前后列值一致，不依赖硬编码财务数字。

2. **指标层（metrics/profitability.py）**：新增 `_safe_or_none`（缺失/NaN → None，区别于 `_safe` 的 0 填充）。毛利率：营业成本 None/NaN/≤0 → None。ROE 回退链分母沿用正确解析后的归母权益列，输入缺失 → None。traffic_light 对 None 维度本就「不计分」，评分侧零改动。

3. **图表层（charts.py）**：
   - 升序：各图表函数入口统一 `annual = list(reversed(annual))`、growth 序列同步反转、热力图行序反转；数据层 collect_chart_data 不动。
   - 禁填 0：`or 0` 全部替换为 `_nan_series`（NaN 断柱）；热力图缺数据格以掩膜数组 + `cmap.set_bad` 灰底 +「缺」文本渲染；增速vs股价图股价涨幅全缺时 `ax.text` 占位说明。
   - 单位：新增 `_YI_FIELDS` 换算，金额序列 /1e8 后渲染，数据标签同步。

## Alternatives Considered

- 只修银行模板列位（44/141 另建映射表）：否——模板随接口演化，位置硬编码会再次漂移，列名匹配才是结构修复。
- 图表层升序改为在 collect_chart_data 输出升序：否——破坏「index 0 = 最新」数据契约，profitability 回退链（`i+1` 取上一年）与 GARP 期次对齐都依赖它。
- 缺失单元格填 NaN 不加占位文本：否——纯 NaN 在热力图里呈现为底色空白，读者仍会问「是 0 还是缺」，占位文本消除歧义。

## Risks

- 下游数值快照变化（ROE/毛利率/权益/PE_ttm）：预期内修复，评估与校准材料若引用旧值需在收口时注明切点；健康度评分因毛利率转 None 而变化，industry-threshold-coverage 的「通用口径」标注逻辑不变。
- 热力图掩膜版式在极端全缺时可能整图灰块：可接受——诚实呈现优于伪值。
- 列名候选误命中（如未来出现含「归属于母公司」前缀的新列）：候选为全名精确匹配（归一化后），非前缀匹配，风险可控。
