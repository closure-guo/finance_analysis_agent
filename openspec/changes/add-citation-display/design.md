# Design: add-citation-display

## 决策

1. **结构化引用随报告下发而非前端解析**：后端已有 Claim/CitationReport 结构，前端只做渲染，避免两端各解析一遍 Markdown 导致编号不一致。
2. **向后兼容**：旧会话无引用字段时前端不渲染任何标记，不报错。
3. **校验状态三级**：verified/failed/unchecked 与 6 类分类法正交——分类是后端内部分析维度，前端只暴露「是否可信」的三级结论，降低理解成本。

## 风险

- **编号漂移**：报告 Markdown 编辑/重渲染后编号错位 → 引用锚点以后端下发的稳定 id 为准，不用序号位置推断。
- **性能**：长报告上百个引用标记 hover 卡 → 预览卡懒渲染，hover 时才挂载。
