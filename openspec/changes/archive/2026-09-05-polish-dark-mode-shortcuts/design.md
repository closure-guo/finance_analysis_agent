# Design: polish-dark-mode-shortcuts

## 决策

1. **class 策略切换暗色**：根元素 `dark` class + 既有 CSS 变量，零额外运行时；ECharts 因 option 已改为读取主题变量，暗色切换即时生效。
2. **命令面板复用会话搜索数据源**：不做新索引，前端内存过滤现有会话列表，百级规模无性能问题。
3. **快捷键集中注册**：单一注册表管理，避免散落监听互相冲突；输入态抑制（输入框聚焦时单键快捷键不触发）。

## 风险

- **暗色下第三方/遗留组件漏色**：依赖「色值全部变量化」的既有契约，验收含暗色逐页检查。
