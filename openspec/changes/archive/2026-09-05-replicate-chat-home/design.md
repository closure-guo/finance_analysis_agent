# Design: replicate-chat-home

## 决策

1. **卡片点击填入而非直接发送**：避免误触发起昂贵的深度分析管线（LLM 成本），用户可再编辑。
2. **空态判定为「会话无消息」**：与路由/会话 id 解耦，新建会话、清空后自然回到空态。
3. **文案静态配置**：建议卡片放前端配置文件，不接后端，避免引入新接口。

## 风险

- **与 assistant-ui Composer 的布局冲突**：空态下输入框居中放大是 Kimi 形态，但为控制复杂度，本 change 输入框位置不变（固定底部），仅空态内容居中——后续如需「首屏居中输入框」另开 change。
