# Design: extend-payout-self-check-coverage

## Approach

三件套修复，全部确定性（零 LLM 参与判定），按「修真错 → 堵源头 → 防误改」分层：

1. **形态扩展**（`validate.py::check_and_fix_stated_ratio`）：替换正则在 `N:1` 之外匹配 `N倍`/`N 倍`。600030 实证形态「赔率约1.78倍纸面占优」——risk_judge 改止损后旧赔率残留，属真自报冲突，替换 100% 修对。窗口扫描逻辑不变（关键词后 40 字符），替换写法 `f"{derived:.2f}倍"` 保持原文风格。

2. **转述护栏**（同一函数）：窗口内含辩论指涉词（批评/激进方/保守方/中性方/对方/辩论）→ 跳过替换、计数 `payout_ratio_conflict_skipped` 并随节点返回（state 键，与 `payout_ratio_corrected` 同级）。理由：601888「激进方对赔率1.55:1不合格的批评被部分采纳」是转述——即使 1.55 无来源（同组价位派生 2.23），替换会反转批评指向（「2.23:1 不合格」语义失真）；冲突计数保留归因可见性，交由评审/批次判定。

3. **终稿价位完整性**（`risk.py` 出口）：action=buy/sell 且价位任一缺失 → 构造打回 feedback 重试一次（复用 `call_llm_for_json` 现有重试通道外的显式一次重跑——与 Trader 价检打回同语义：首次打回、二次放行+标注 `final_price_check` note）。不重跑关系/参考带校验（终稿价位以 Trader 已校验价位为基线，risk_judge 只做继承或显式改写）。

## Alternatives Considered

- **FM（fund_manager）出口补挂自检**（立项时最初设想）：否决。FM reasoning 为审批转述文本（「采纳/驳回/批准」），其中数字多为转述辩论原文，原位替换错改风险高于收益；且两个真实漏网（形态盲区、价位缺失）都在 risk_judge 出口可修，FM 层残余矛盾（转述型）由护栏计数 + B5c 评审层覆盖。601888 实测佐证：FM 与终稿 reasoning 同含 1.55，皆为转述。
- **从 reasoning 文本反提价位**（601888 的价位埋在文本）：否决。文本提取不可靠（「止损49.50以条件单绑定失效位49.86」有两个数字、无结构角色），结构化打回（方案 3）让 LLM 自己申报才是价位必填化已确立的语义。
- **替换时语义方向判断**（判断批评句替换后语义是否反转）：否决。需要 NLU，违背确定性自检的无 LLM 原则；护栏（跳过+计数）以保守性换确定性。

## Risks

- **打回重试增加 risk_judge LLM 调用**：仅在终稿 buy/sell 价位缺失时发生（实测 20 标的 1 例 = 5%，单次重试 ≈ +1 调用/标的），可接受。
- **N倍 正则误匹配**：窗口内非赔率语义的「N倍」（如「2倍 VaR」）——由赔率关键词前置约束（窗口锚定「赔率/盈亏比」后 40 字符内）缓解；`2倍VaR` 紧跟「VaR」不跟在赔率关键词后，不进窗口。
- **转述护栏词表覆盖不全**：词表为实证枚举（六词），长尾转述形态可能仍被替换——护栏是风险削减而非根除，计数键使残余可观测（批次归因可见）。
