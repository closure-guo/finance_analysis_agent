# Design: resolve-report-relevance-zero-variance

## Approach

两条腿分开处置：quick 条目**停评**（零方差 + 判据失败面被确定性指标覆盖 + K 均值后成本 ×K，信息/成本比不支持保留）；deep 条目**收紧**而非退役（4.86/4.93 的真实方差说明该维在 deep 多焦点查询下有区分力，r2 的 4.86 正是真实切题缺陷被抓住的样本）。收紧方式沿用本项目已验证的「5 分档锚点判例」模式（debate v4 → v6 的同款思路：把 5 分从「总体切题」收紧为「显式子问题逐一回答」），并按校准门禁以 round7 盲标样本离线重判验证。

## Alternatives Considered

- **quick 降频抽样评（如每 3 轮评 1 轮）**：零方差维度抽样后仍是零方差，只省了成本不解决口径问题；且「哪轮评哪轮不评」成为新的口径负担。
- **report_relevance 全量退役（deep 也删）**：deep 段存在真实方差与真实失败模式（r2 4.86），退役会丢掉唯一回答「报告是否回答了用户问题」的维度——这是因果上依赖「查询→报告」链路的指标，不属「通用正确性指标」。
- **构造性判据替换**（把切题度确定性化为 query 关键词/标的/焦点 vs 章节映射）：语义对齐仍需 LLM，确定性化只能覆盖结构面（已被 section_coverage 覆盖）；完整替换需新校准轮投入，收益不明确，留作 v4 判例生效后若仍无区分力的再评估项。

## Risks

- **quick 条目失去全部 judge 信号**：接受——quick 的失败面（解析错标的、章节缺失、引用断链）恰好都在确定性指标覆盖内；若未来 quick 质量事故超出该覆盖面，以其为反向证据重开 judge。
- **rubric v4 收紧后 deep 均值下移**：预期效果（裁判变严非质量下降，同 r8/r9 dg 先例），以切点行 + 契约抽验（降分行 reason 是否指向真实被回避子问题）区分，不误读为质量回归。
- **校准样本时效**：round7 样本（2026-09-13）重判 v4 时材料口径早于后续切点（锚点骨架行、决策契约字段）——重判只校准 report_relevance 单维，材料只含 query + report，不受上述切点影响。
