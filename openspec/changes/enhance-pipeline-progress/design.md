# Design: enhance-pipeline-progress

## 决策

1. **复用现有事件流**：timeline_builder 已产出结构化节点事件，本 change 仅重做展示层，零后端改动。
2. **四态状态机**：等待/运行/完成/失败与后端节点状态一一映射，失败态不阻塞其余节点展示。
3. **完成后折叠**：报告就绪后时间线折叠为摘要条，把屏幕让给报告，细节可再展开——对齐 Kimi 深度研究的收尾形态。

## 风险

- **刷新重建**：刷新后需从快照重建时间线状态（沿用 restore-session-on-refresh 的快照路径），缺失事件时按落库数据重建为完成态。
