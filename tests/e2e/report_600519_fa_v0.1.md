## 一、严重错误（P0）

### 1. 存货周转率严重失实

| 项目         | 报告数据 | 实际数据  | 偏差     |
| ------------ | -------- | --------- | -------- |
| 存货周转率   | 0.08 次  | 0.2573 次 | **-69%** |
| 存货周转天数 | 未提及   | 1,399 天  | —        |

**根因**：`metrics/efficiency.py` 计算公式或列名映射有误，需排查修正。

**定性影响**：报告据此推断"库存积压严重"，实际上白酒基酒需陈酿 3-5 年是行业正常特性。用快消品标准评价白酒行业属于削足适履。2025 年白酒行业产量同比下降 12.1%，连续第九年下降，茅台存货管理远优于行业平均。

### 2. 利息覆盖倍数标红灯逻辑错误

| 项目         | 报告数据                   | 实际数据             |
| ------------ | -------------------------- | -------------------- |
| 利息覆盖倍数 | 3994.6x（从 8266.4x 下降） | **-13,976x（负数）** |

**根因**：茅台几乎没有有息负债，利息收入大于利息支出。AKShare 返回的"利息支付倍数"为负值（净利息收入者），系统取绝对值后判定。变化率阈值一刀切：>50% 下降就标红，完全不考虑绝对值水平已极安全。

**实际含义**：茅台是净贷款方（账上现金 1,264 亿），利息覆盖倍数对这个公司毫无意义。将其标为"红灯风险指标"是根本性误判。

### 3. 经营现金流归因错误

| 项目              | 报告数据                 | 实际数据                                        |
| ----------------- | ------------------------ | ----------------------------------------------- |
| 经营现金流/净利润 | 0.72，同比下降 30.3%     | 约 0.75（615.22 亿 / 823.20 亿）                |
| 下降原因          | 报告归因为"利润含金量低" | **主因：财务公司存款变动 + 法定存款准备金增加** |

**根因**：LLM 在无行业上下文的情况下，将现金流下降机械归因为经营恶化。实际上，茅台核心白酒业务的销售回款仍在增长，现金流下降来自金融子公司的存款业务调整，与卖酒业务无关。

### 4. 综合评级"关注"严重失实

**报告结论**：60.8 分，"关注"评级。

**实际情况**：

- 毛利率 91.18%（A 股最高之一）
- 净利率 50.53%
- ROE 33.65%
- 资产负债率 16.42%（极低）
- 账上现金超 1,264 亿
- 分红率 79%
- 在 2025 年白酒行业营收整体下降 18.85% 的背景下，茅台仅下降 1.2%，远优于同行

**根因**：评分模型被错误指标（存货周转率 0.08、利息覆盖红灯）拉低，导致健康度评分严重偏低。一家毛利率 91%、ROE 34%、负债率 16%、现金千亿的公司不可能是"关注"评级。

## 八、优化对策

### 对策 1：修复指标计算 bug（P0，改代码）

**存货周转率（`metrics/efficiency.py`）**：

- 排查列名映射，确保用正确的"营业成本"和"存货"字段

**利息覆盖倍数（`metrics/solvency.py`）**：

- 处理负值情况：当利息费用为负（即利息收入 > 利息支出）时，标记为"净利息收入者"，不参与红黄绿灯评判
- 在 `traffic_light.py` 中跳过值为负数的指标

### 对策 2：改进评分模型（P1，改 `traffic_light.py`）

**加安全地板规则**：

- 当指标绝对值已达到优良标准时，变化率不触发红灯，最高降为黄灯
- 具体规则：若绝对值灯色为绿灯，则最终灯色 = max(绿灯, 变化率灯色降一级)
- 例如：利息覆盖 3994x（绝对值绿灯）+ 变化率 -52%（变化率红灯）→ 最终黄灯而非红灯

**指标适用性过滤**：

- 利息覆盖倍数：当公司为净利息收入者（利息费用 < 0）时，该指标标记为"不适用"，不参与评分
- 应收账款周转率：当应收账款接近零（如茅台预付款模式）时，该指标标记为"不适用"

### 对策 3：补充关键指标（P1，新模块 + 扩展数据拉取）

**新增指标模块**：

- `metrics/dividend.py`：分红分析（分红率、股息率、分红趋势）
- `formatters.py` 新增：`format_revenue_summary`（营收/利润绝对值 + 同比）

**扩展 AKShare 数据拉取**：

**在 `compute.py` 中补充**：

- 分红率和股息率

### 对策 4：Prompt 注入行业上下文（P2，改 `prompts/`）

**行业信息注入机制**：

- `formatters.py` 新增 `format_industry_context(industry_info)`：将行业名称、特征、关键背景格式化为文本
- 预置行业特征库（`industry_profiles.py`）：
  - 白酒：存货为基酒增值资产、经销商预付款模式、品牌溢价极高
  - 银行/保险：高杠杆是正常属性、用资本充足率而非资产负债率评判
  - 零售/快消：存货周转率是核心指标、低毛利高周转模式
- 在 FA 分析 prompt 中加入行业特征段落，引导 LLM 结合行业背景解读指标

**归因逻辑引导**：

  - 分析变动原因时，先判断是核心业务因素还是非经营因素（如金融子公司、会计变更）
  - 杜邦分析要区分"因"和"果"：规模变动导致利润率变化，不是反过来
  - 不要孤立评价单一指标，必须结合其他指标和行业背景综合判断
